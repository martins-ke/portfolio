ShopLite POS & Inventory Management System

A high-concurrency retail point-of-sale and inventory backend built in Java and Spring Boot, focusing on transactional integrity, atomic inventory decrements, and sales audit logging.

Project Type Backend POS Engine
Core Technology Java • Spring Boot
Database Relational MySQL Schema
Key Highlight ACID Atomic Checkouts
Engineering Focus

Architectural Design & ACID Invariants

When processing high-velocity retail checkouts, race conditions can easily cause negative inventory balances or inconsistent ledger tallies. ShopLite was architected to handle these challenges cleanly:

Atomic Inventory Decrements: Every sales transaction verifies item stock level in real-time. If stock is insufficient, the entire checkout rolls back with zero partial data writes.
Deterministic Receipt & Tax Calculation: Tax levies and discount deductions are calculated with `BigDecimal` arithmetic to prevent floating-point rounding errors.
Auditable Ledger Schema: Completed sales generate immutable audit logs that link each transaction line item to cashier sessions and warehouse stock states.
Capabilities

Core System Capabilities

  • Barcode & SKU Lookup: Fast indexed searching of product inventory.
  • Multi-tender Payment Support: Cash, card, and split-tender payment handling.
  • End-of-Day Cashier Reconciliation: Shift closing and cash drawer variance reporting.
  • Low-Stock Alerts: Automated threshold monitoring to notify store managers before stock runs out.
